## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] `LayoutProps` undefined for standalone `tsc --noEmit`**
- **Found during:** Task 3 verify
- **Issue:** The scaffold's `RootLayout({ children }: LayoutProps<"/">)` relies on a global type that only exists after `next build`/`next typegen` writes `.next/types`. On a clean checkout `tsc --noEmit` failed with TS2304.
- **Fix:** Typed the props explicitly as `Readonly<{ children: React.ReactNode }>`.
- **Files:** app/layout.tsx
- **Commit:** 7e2c86b

**2. [Rule 1 - Bug] smoke.mjs `--expect-404` broken under Git Bash, plus a DEP0190 warning**
- **Found during:** Task 3 verify
- **Issue:** MSYS rewrites `/no-existe` to `C:/Program Files/Git/no-existe`, so the fetch failed. Separately, `spawn(cmd, args, { shell: true })` printed Node DEP0190.
- **Fix:** Paths that do not start with `/` are now rejected with a hint to use `MSYS_NO_PATHCONV=1`. On Windows the script spawns a single command string after validating that the port is numeric. `taskkill` runs synchronously so the server is stopped before exit.
- **Files:** scripts/smoke.mjs
- **Commit:** 7e2c86b

### Notes (not deviations)

- `npm install` (npm 11) reported that `unrs-resolver@1.12.2` (a transitive ESLint resolver dependency) has an install script not covered by `allowScripts`, so it was not run. Lint works without it. I did not approve it.
- `next build` fetched Open-Meteo twice, once per prerendered route, because the build workers are separate. That is two calls per deploy, which is well within limits.
- The scaffold left `public/` empty after the demo SVGs were removed, so git does not track it.
